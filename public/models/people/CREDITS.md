# People: sources and licences

Everything in this folder is generated by `blender/make_humans.py` (see `blender/README.md`).
It is derived only from these sources:

| what | source | licence |
| --- | --- | --- |
| base mesh, macro and face targets, game-engine rig and its weights | MPFB2 data (`src/mpfb/data`), MakeHuman Community, https://github.com/makehumancommunity/mpfb2 | CC0 1.0 (`LICENSE.ASSETS.md` in that repository) |
| skins (diffuse textures), eyes, eyebrows, eyelashes, hair, clothes and shoes (meshes, diffuse, normal and AO maps) | MakeHuman system assets, `makehuman_system_assets_cc0.zip`, https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html | CC0 1.0 ("explicitly released as CC0 in September 2020", Data Collection AB, Joel Palmius, Jonas Hauquier) |
| the dog | `blender/bld/people.py` (this project) | the project's own |
| pores, freckles, blotches, weave and wear | procedural Blender nodes in `blender/bld/humans.py` (this project) | the project's own |

MPFB2's add-on code (GPL-3.0) is only used as a tool at build time; none of it ships.
No MetaHuman, Mixamo, Ready Player Me, Daz or Sketchfab material is used. CC0 needs no
attribution; it is given anyway.
